# 日本留学私塾 - 自媒体工作台

一个面向自媒体团队的**内容生产协作平台**（单文件 Web 应用），覆盖从灵感到复盘的完整内容流水线，支持**多人云端协作**。

> 🔗 在线使用：https://newfield-content-hub.app.workbuddy.host/
>
> 也可以直接下载 `index.html` 用浏览器打开使用（数据仍存云端，跨设备共享）。

## ✨ 功能模块

### 💡 灵感收集
- 随手记录内容灵感：**主题**（必填）、补充说明、标签
- **负责人**必选，**提交日期**默认当天、**发布截至日**默认一周后（均为必填）
- 形式选择：**图文 / 视频 / 图文+视频**（单选下拉）
- **参考链接/对标链接** 记录对标账号或素材来源
- 三项自评：**客户吸引力 / 产宣价值 / 重要紧急度**（高·中·低）
- 一键「**确定为价值选题**」：弹窗确认三项评估（必选），确认后状态置为「待排期」进入选题排期

### 🎯 选题排期
- 对候选选题评估 **客户吸引力 / 产宣价值 / 重要紧急度**（高中低，卡片上直接点选）
- 「**确定排期**」弹窗：**制作人、审核人、发布截至日**为必填项，确认后状态置为「待制作」进入制作进展

### 🗓️ 排期与进展
- **双周历视图**（14 天，按发布截至日排布，可前后翻页）
- **制作进展管理表**：负责人 / 制作人 / 审核人 / 当前状态，直接在列表内调整

### 📋 制作进展
- 状态机：**待入选 → 待排期 → 待制作 → 待审核 → 已发布 → 已复盘**
- 「补充内容脚本」：口播稿 / 分镜 / 文案正文随时补充
- 「调整排期」修改发布截至日等信息；状态改为「已发布」后可一键送复盘

### 📊 复盘优化
- 记录发布后关键度量数据：**曝光/阅读、点赞、评论、涨粉、收藏、转发**
- 「做得好 / 问题 / 改进」三栏复盘，优秀思路可一键存回灵感池形成闭环

### 🏠 总览
- 内容统计 + **🔥 Top3 数据表现**（曝光/阅读、点赞榜单）
- 近期排期（按发布截至日）、全部选题列表（含三项评估、状态、发布截至日、负责人）

## 👥 多人协作

- **云端共享数据库**：所有成员看到同一份数据，页面每 5 秒自动同步
- 右上角切换当前身份，成员管理页维护团队名单（嘉伦、李老师、王老师、刘老师、陈老师…）
- 每条内容带负责人 / 制作人 / 审核人，总览可看按人分工
- **CSV 导出**：一键导出全部数据（25 列，带 BOM，Excel 直接打开不乱码）

## 🛠️ 技术实现

| 项目 | 说明 |
|---|---|
| 架构 | 单文件 Web 应用（`index.html`，零构建、零依赖安装） |
| 存储 | WorkBuddy 云数据库（PostgreSQL + RLS，`items` / `members` 两表） |
| 同步 | 前端每 5 秒轮询，近实时多人协作 |
| 状态归一 | 旧数据自动映射到新状态机，升级无需手工迁移 |
| 数据安全 | 灵感 / 脚本 / 复盘数据全部云端存储，支持 CSV 快照导出 |

## 🚀 快速开始

1. 打开线上链接（或本地打开 `index.html`）
2. 首次访问自动生成演示数据（可删除）
3. 右上角「我是」选择你的身份，开始使用

## 📌 适用场景

留学机构 / 教培团队 / MCN 小组等需要多人协作生产自媒体内容（小红书、公众号、视频号等）的团队，特别是需要**选题评估打分 → 排期 → 制作进度跟踪 → 数据复盘**这套标准流程的团队。
